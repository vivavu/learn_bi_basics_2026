# Implementation Guide for learn_bi_basics_2026

This document is the dedicated implementation guide for the repository. It is separate from the original `README.md` and focuses on the practical Power BI workflow, templates, and troubleshooting.

---

## Purpose

This implementation guide is for learners who have already completed foundational BI training (for example, Codecademy or Microsoft Learn) and want to apply that knowledge using this repository.

It is designed to help you:
- build a working dashboard quickly
- use the repository materials effectively
- avoid common implementation blockers
- leverage Microsoft Learn only for concept review

## Recommended Workflow

1. **Verify your environment**
   - Start with [PREREQUISITES.md](../PREREQUISITES.md)
   - Confirm Power BI Desktop is installed and your data files are accessible

2. **Build a confidence dashboard**
   - Follow [QUICK_START.md](../QUICK_START.md)
   - This ensures your setup works before you begin the main course

3. **Use the original course flow**
   - The `contents/` folder contains the role-play prompts for:
     - Phase 1: Business Requirements
     - Phase 2: Data Modeling
     - Phase 3: Visualization Design
     - Phase 4: Dashboard Development

4. **Follow the Power BI implementation guide**
   - Use [IMPLEMENTATION_GUIDES/Phase_4_Power_BI_Walkthrough.md](Phase_4_Power_BI_Walkthrough.md) when you build the dashboard

5. **Use templates and recipes as needed**
   - DAX formulas: [IMPLEMENTATION_GUIDES/DAX_Templates.md](DAX_Templates.md)
   - Power Query recipes: [IMPLEMENTATION_GUIDES/Power_Query_Recipes.md](Power_Query_Recipes.md)

6. **Troubleshoot quickly**
   - If you hit a blocker, search [IMPLEMENTATION_GUIDES/Troubleshooting.md](Troubleshooting.md)

7. **Review key decisions**
   - When unsure, consult [REFERENCE_MATERIALS.md](../REFERENCE_MATERIALS.md) for glossaries and decision matrices
